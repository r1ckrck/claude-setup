# 3D / WebGL

**When** → real 3D, shaders, or depth: hero shaders, ambient glow, photoreal captures, interactive scenes.

**Default** → **React Three Fiber + drei** — React renderer for Three.js with helpers.

**Reach for**
- **@react-three/postprocessing** — bloom / glow / depth post-effects.
- **GLSL shaders** — bespoke gradient/ink/discipline blends.
- **3D Gaussian Splatting** via drei `<Splat>` — photoreal captures of real builds (heavy files).
- **Spline** — no-code 3D when authoring in-browser beats writing R3F.

**Rules**
- **Gate behind a capability check** with a **static fallback** — never block first paint on WebGL.
- Honor reduced-motion and mobile/perf budgets; 3D is the first thing to drop on weak devices.
- Heavy assets (splats) load lazily, off the critical path.

**Deps** → **import** (three / R3F / drei are irreducible engines).

**Tier** → T1+ for ambient shaders; interactive scenes typically T2+.
